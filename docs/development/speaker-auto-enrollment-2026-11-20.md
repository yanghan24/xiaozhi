# 新音箱首次联网自动登记方案

新音箱开机后沿用当前 Wi‑Fi 配置。首次联网时，由音箱使用本机生成并持久保存的独立登记身份向小智后台建档。后台先允许这台设备扫码，用户在 AI 集市授权后，音箱自动领取并保存正式设备凭据。已交付设备继续使用原凭据及绑定。

1. Java API 新增首次接入入口。登记可以重试，待绑定设备只有扫码授权权限。扫码成功后，后台向同一登记身份签发正式凭据，音箱保存成功后确认收件。正式凭据启用后沿用现有设备鉴权、心跳、OTA 和语音入口。
2. P4X 固件在当前账号模块内处理首次联网和凭据持久化，沿用 Wi‑Fi 配网和扫码界面。新设备在 `/state`、心跳和 OTA 上使用正式凭据。已有凭据的音箱从原有账号流程启动。
3. 服务端和固件分别验收。覆盖登记重试、错误登记凭据、绑定前的权限、绑定后自动领证、重启继续已有绑定。开发验证通过后更新 114 的 API，再清空并写入指定测试音箱。实机数据按用户要求直接擦除。

固件右上角入口为「账号」。准备登录时，在现有状态栏通过 `ShowNotification()` 短暂显示「正在准备登录」。登记与发码合并为这条提示，扫码、重试和账号详情使用现有账号界面。后续需要展示的新状态复用 `SetStatus()` 或 `ShowNotification()`。
