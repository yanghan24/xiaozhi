# P4X 音箱触屏 Wi-Fi 配网

以固件 2.6.17 为基线，在现有手机热点配网上增加音箱触屏入口。沿用小智的 Wi-Fi 扫描、连接验证、本机保存和重连。微雪 WLAN 页用于核对 LVGL 密码框、屏幕键盘和返回交互。

## 页面和导航

| 左列 | 右列 |
| --- | --- |
| 账号 | Wi-Fi |
| 声音和显示 | 屏保 |
| 关于设备 | |

设置首页保留 91 像素卡片高度、16 像素间距、两列和底部返回手势区。Wi-Fi 模块采用现有 800×480 深蓝主题。

1. **Wi-Fi 首页**显示当前网络和连接状态，已联网时提供「更换网络」，未联网时提供「选择网络」。两种状态都可以直接进入「用手机配网」。访问首页时保持当前连接，开始更换网络或手机配网时才进入现有配网模式。
2. **附近网络**显示网络名、信号、是否需要密码，支持手动刷新和滚动。开放网络直接试连，加密网络进入密码页。
3. **输入密码**显示目标网络，单行密码框默认遮挡。复用 LVGL 触屏键盘的大小写、数字、符号、空格和退格。确认后连接，取消清空输入并返回列表。连接失败可重试。
4. **用手机配网**显示原有热点名和网页地址。用户使用手机浏览器在现有网页完成选网和密码输入。

## 模块职责

- 设置导航注册 Wi-Fi 入口。Wi-Fi 页面模块独立管理页面、键盘和连接反馈。首次无网和启动连接超时进入同一 Wi-Fi 首页，不依赖账号或语音连接。
- 音箱与手机通过当前配网组件扫描和试连，连接尝试串行执行。验证目标网络拿到 IP 后，使用已有存储格式保存并退出配网。原网络记录在失败或取消时仍可用，取消换网后由原有启动连接逻辑恢复。
- 开机 OTA 后继续读原有 Wi-Fi 记录。新机联网后走现有设备登记和 AI 集市扫码流程，已绑定音箱联网后恢复原账号和语音服务。

## 实施及验收

1. 接入触屏可调用的配网能力，核对现有手机热点入口、连接和保存仍由同一个组件处理。
2. 实现 Wi-Fi 独立页面、键盘、设置导航和首次开机入口，按阶段提交。
3. 在开发容器验证构建、分区余量、触控导航和配网状态。真机单独验证首次配网、密码错误重试、取消换网后恢复、手机热点备用和已配网设备 OTA 后自动联网。

## 实现和开发验证

- `115f66e` 接通触屏配网。触屏通过本机回环地址调用现有热点网页使用的扫描、提交和退出接口，同一 HTTP 服务串行处理请求。试连取得 IP 后保存，主动切换或取消时优先尝试相应网络一次，后续由原有自动连接策略接管。
- `bafe890` 实现四个 Wi-Fi 页面、两列设置菜单和首次开机配网入口。使用现有深蓝组件和 LVGL 原生触屏键盘。Wi-Fi 页面同样用于启动连接超时。
- P4X 中文集市版构建通过，应用镜像 4,123,904 字节，OTA 应用槽余 4,864 字节。镜像 SHA-256 为 `9a397c0e72234763d99b6dbc4476c47cf4b5dca78485859df3860d60322045f3`，构建保留 2.6.17 版本号供开发检查。
- 800×480 LVGL 模拟检查通过，覆盖五项菜单排布、首启入口、触屏按键、取消清空密码、连接失败重试、手机热点信息和取消换网回连请求。使用模拟配网接口核对扫描结果解码、连接请求、回连网络和串行提交。既有热点网页的组件检查通过。
- 固件主机测试运行 179 项，通过 164 项，跳过 15 项。容器内 LeakSanitizer 无法运行，复跑时关闭该项检测。DHCP 获取地址、实际换网和回连、手机热点以及 OTA 保留旧网络需要真机验收。本次交付限于开发环境。
