# 原账号设备页与单台退出（#13）

> 2026-11-10 后续实现：恢复许可、语音闸门和直连集市模型见[产品语音说明](customer-product-voice.md)。本文保留前一切片的范围和证据。

本切片在手机确认绑定之后补齐原账号设备页面、account 请求消费、单台退出及停播 ACK 状态。所有产品语音仍保持 blocked；不实现恢复 allowed、语音令牌、语音输出闸门或集市授权失效传播，不宣称跨服务停止实际播放已验收。

## 使用路径

绑定成功页的“账号与绑定”链接进入本次设备页面。已有设备可通过正式 account 请求完成 OIDC 后点击“进入本台设备页”；`open-account` 只接受 account 用途、当前原归属账号、未过期请求与匹配的凭据/许可版本，消费请求并创建页面上下文，推进 revision，不改变归属代际或许可版本。可信身份无需具备可用业务 Key 才能管理退出。

当前阶段 device_disabled 仍禁止申请设备二维码；刚绑定且采用该阶段性语音禁用状态的设备可从绑定成功页进入已建立的页面上下文。此限制随产品许可/语音切片一并解除，不放宽管理员禁用或独立设备准入。

手机页面 `/xiaozhi/customer/devices/{device_session_id}` 使用 Secure/HttpOnly 客户 Cookie。按钮显式 POST `device-sessions/{id}/sign-out`，表单携带 CSRF 和固定操作键，成功 303 返回页面。账号入口有独立 open-account 表单；JSON 接口保持协议既有路径、空对象请求、数值版本和 v1 封装，Schema/报文形状不变。Nginx 仅开放新增精确路径。

## 退出与重放

页面上下文只是选择符，每次读取/操作均校验原浏览器、30 分钟闲置、身份未注销、准入/凭据快照、当前归属与归属代际。变更还验证精确 Origin、CSRF、幂等键及页面保存的许可版本。与后通道注销共用短事务屏障，事务不发起集市网络请求。

退出原子保存 `blocked/user_signed_out`、推进 permission_version/revision、作废当前二维码并记录操作结果。归属、其他设备、共享 Key/Refresh 和授权记录不变，不调用集市全局登出。操作结果保存于 `customer_device_operation`（迁移 202611101000）；同页面同键重试返回原结果，不再次推进版本，旧页面的新操作不能覆盖后来状态。历史重试仍要求当前身份、准入、凭据和归属有效。

成功的请求可在原二维码 600 秒之后使用页面，直到客户闲置期限届满。设备页、flow 和操作 GET 均不续闲置期限；显式成功操作续期。页面自然到期不会退出音箱。幂等记录暂不清理，保留超过契约要求的 24 小时。

## 可观察状态与边界

- `stored`：服务器退出已保存，页面显示“退出已保存，等待音箱确认停播”，离线设备同样如此。
- `device_acknowledged`：当前许可版本仍对应本次退出，并存在该版本且 revision 不早于退出的 `audio_stopped=true` ACK。
- `superseded`：当前许可版本已变化，旧 ACK 或历史成功重放不能当作新一次退出的完成证据。

控制长轮询沿用数据库持久 revision 与跨实例 200 ms 检查，进程重启可读回归属、停用及操作结果。当前没有可用语音租约，数据库控制状态不能代替未来语音调用/输出保护；真实音箱停播速度、固件清队列、通知与音频仍待真机验证。resume 保持拒绝，不把账号页登录当成恢复使用。

## 回退
