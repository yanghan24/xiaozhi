# P4X 深蓝界面实施

2026-11-21 确认以深蓝修订稿为基准，目标为筑音 P4X 4.3 寸 800×480 横屏。开发验证和真机验收分别记录。

1. 页面导航统一管理全屏页面、返回和边缘手势。首页、开机动画、5 分钟屏保各自管理显示。只有首页和屏保右上角显示 Wi-Fi。
2. 首页左侧为五个等尺寸、三列对齐的应用图标，右侧为时钟。设置首版只有账号。绑定详情、扫码登录和解除绑定沿用账号模块状态；首次扫码保持系统流程的显示优先级。
3. 日历自周一至周日显示一周，日期条内横滑切周，下方列出选中日期的本地记事。音乐、录音和番茄钟使用各自现有功能模块，并接入公共返回；录音和保存阶段沿用退出限制。
4. 对话页显示居中大字和底部彩色波带，复用连接、收音、识别结果、等待和实际播报事件。开机和对话动效分别由显示模块驱动。

实施按公共界面与系统画面、应用适配、开发验证分阶段核对。固件开发候选使用现有 P4X 构建环境。验证覆盖触摸坐标、切周和返回识别、录音退出保护、系统页面优先级、日程与对话显示和 OTA 应用分区容量。生产发布和真机刷写分别安排。

## 2.6.13 静态底图

首页、屏保和开机页分别使用按深蓝定稿制作的 800×480 无字 JPEG 底图，三张共 24,404 字节，直接嵌入 P4X 应用固件。时钟、天气、Wi-Fi、卡片和 Logo 继续由页面组件绘制。固件调用 P4X 硬件解码器把底图转为 RGB565，解码失败时使用页面底色。首页缓存已解码的底图，屏保和开机画面隐藏后释放各自的缓冲。

固件提交 `c903fbc564e5aa3fd192e15c8f5d433a97ccb071`。P4X 构建及镜像校验通过，应用镜像为 4,050,656 字节，OTA 应用分区剩余 78,112 字节。LVGL 800×480 模拟使用三张底图的 RGB565 像素验证了开机叠层、首页触摸、两次进入屏保和点击返回。模拟中对话波带仍按现有刷新范围运行。P4X 真机解码和显示待验收。
