## S2：身份与原版连接边界

- 扫码授权只保存身份和用户设备关系，不再申请资源 Key；openid/profile/organization/balance:read/offline_access 保持，移除 credentials:manage 请求。已知授权失效拒绝使用，临时刷新不确定不误解绑。
- 原版 WebSocket/ConnectionHandler 加入独立身份会话；连接时验证、轮次边界检查配置、独立两秒撤销检查，不逐帧/逐 token 查询。解绑、停用使旧票据和会话失效。
- 完整 ai_agent 复用原版 ConfigService 的全部模块、提示词、音色、插件和上下文配置；选择变化时等待当前生成/播放结束，重建原版提供者并清空对话。退役 TTS 工作者独立结束。流式 ASR 在替换接收器时保护已识别问题的交接。
- 记忆作用域按用户/设备/配置版本隔离，不向新客户返回共享角色的旧 summaryMemory；持久化记忆和历史归属适配在 S3 完成。
- Java 定向 23 项通过，修改配置一致性后相关 8 项重跑通过；Python 原版流式与身份/角色边界 7 项通过。日志 restoration-s2-tests.log、restoration-s2-final.log、restoration-s2-python.log。均无真实集市授权或外部模型调用，尚未据此宣布完整联调。
