# P4X 对话动效和 LCD 诊断

2.6.9 实机在对话中偶发整屏闪蓝。LCD 扫描供数不足是当前排查方向，需由驱动事件验证。

1. 对话波带集中在底部 60 像素，以约 12 帧每秒绘制主波纹。连接与等待期间保持静止，收音及实际播报期间播放。开机、首页和屏保沿用其静态效果。
2. 在 P4X 显示驱动的 `underrun` 中断分支累计事件，定期记录对话显示状态、波带是否绘制及所处心跳窗口。音箱继续使用现有设备诊断开关、30 分钟有效期、鉴权心跳和日志批次。
3. 管理 API 继续接受旧固件的报告，设备详情增加 LCD 诊断事件的显示。按管理 API 与页面、OTA 应用固件的顺序发布。

开发检查覆盖波带区域、频率与状态切换，缺帧汇总、超时、重试及旧日志兼容。真机升级和闪蓝复查分别记录。
