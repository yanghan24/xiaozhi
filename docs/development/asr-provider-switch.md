# 产品语音识别服务切换

2026-11-13 用户要求在小智管理后台切换 AI 集市与独立讯飞实时语音转写大模型。此设置只改变语音识别来源；设备归属、本地调用许可、集市身份授权、对话模型与 TTS 沿用当前规则。讯飞直连使用运营方独立额度，不使用归属账号的集市转写额度。

## 管理入口与生效方式

管理员进入「模型配置 → 语音识别」，在「小智设备语音识别」区域选择 AI 集市或讯飞直连。首次配置讯飞需要 APPID、APIKey、APISecret；三项全部留空保留旧凭据，修改时必须完整提交。切回集市不删除讯飞配置。页面和响应只返回凭据是否已配置，不回显秘密。

这是全局设置。保存后每段录音开始转写时读取一次，已开始的转写完成于原服务；后续录音使用新选择，无需重启或重连设备。初始化默认为集市；失败、超额和并发限制不会触发自动切换或重试。未实现讯飞余额查询或超过两并发时的排队。

## 边界与保存

`/admin/product-asr` 的 GET/PUT 需要 `sys:role:superAdmin`。PUT 携带读取到的 revision，过期版本返回 409。服务、密钥和版本在单条事务中保存到专用 `product_asr_settings` 表；APIKey/APISecret/APPID 使用现有身份加密密钥做 AES-GCM 加密，不进入通用参数或模型配置接口。管理接口及内部接口均返回 no-store。

私有语音权威接口新增 `asr-access`，要求服务凭据与有效语音会话，读取配置前后检查设备许可。每段发送、收取及上游沉默期间继续检查许可；取消、断线、退出会关闭上游连接。讯飞 401 不撤销集市授权；集市 401 仍走原持久失效上报路径。

讯飞固定连接 `wss://office-api-ast-dx.iflyaisol.com/ast/communicate/v1`，不接受管理员自定义目的地址。按[官方协议](https://www.xfyun.cn/doc/spark/asr_llm/rtasr_llm.html)以排序后的查询参数、HMAC-SHA1 和 Base64 签名，每次生成独立 uuid。音频格式、实时发送节奏、最终文本拼接、时限与内存限制复用 [rtasr-llm 协议实现](rtasr-llm.md)。签名 URL、请求头和凭据不写日志。

## 验证与回退

- `CustomerVoicePermissionHttpTest`：真实 HTTP、MySQL 与管理员鉴权，凭据加密、不回显、版本冲突、切回保留配置、退出后拒绝取用。
- `scripts/test_product_rtasr.py`：真实本机 WebSocket，签名与无集市头、现有连接双向切换、讯飞 401 隔离、取消与失效；兼容原集市协议测试。
- `CustomerVoiceHarness` + `scripts/check-product-asr.py`：分别用集市和讯飞模拟外部服务，正式设备 Opus → 转写 → 对话 → TTS、取消、断线与退出后禁用。`ASR_TEST_PROVIDER=xfyun` 仅用于隔离夹具。
- 前端组件测试验证不重试保存、冲突提示、保留/清空密钥输入与失败后禁止保存。

迁移只新增表，旧服务可忽略该表。回退应用需同时恢复原产品 API、语音与管理页面镜像，保留新表、加密密钥、设备归属和持久失效记录；回退后的旧语音仍固定走集市。备份应包含 `product_asr_settings` 及原加密密钥，不包含录音或对话正文。
