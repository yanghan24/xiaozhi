# P4X 待机天气、本地媒体与对话页面

> **归档｜交付或验证记录**。正文对应当时的版本、范围和结果。当前入口见[项目文档](../../../README.md)。

本轮基于 P4X 4.3 寸 2.6.7。旧版用于核对横屏视觉和板卡硬件信息。新增功能按当前系统的模块和接口实现。

1. 高德 IP 定位和实时天气由 Java 后台调用。两项向「第三方服务」读取同一份认证配置。音箱按设备身份拉取待机天气，网络和数据刷新独立于语音与显示线程。和风及太平洋电脑网的配置继续复用现有入口。开发凭据沿用开发环境已经保存的配置。
2. SD 卡提供独立的挂载和文件访问模块。媒体页面读取本机文件并提供播放控制。使用现有音频输出任务，发起对话时停止本地音乐并清除待播帧。
3. 录音页面调用独立录音模块。麦克风由音频服务独占给录音，后台任务写入并完成 WAV 文件。结束后恢复待机唤醒。
4. P4X 对话页面改为独立全屏视图，参考旧版 Logo、圆环、状态栏、结束按钮和字幕布局。连接和收音跟随应用状态，回复动画跟随音频输出和播放完成事件。

按阶段提交并核对开发构建。生产发布和实机验收另行安排。空气质量与天气 MCP 留到后续阶段。

Java 定向测试 6 项通过，覆盖设备鉴权、待机权限独立、两次供应商请求的参数、缓存和加密配置。固件构建测试运行 179 项，164 项通过，15 项因可选依赖跳过。容器内 LeakSanitizer 无法运行，使用其余 AddressSanitizer 检查重跑。LVGL 检查通过全屏尺寸、字幕、动画启停和结束按钮。生成的 PCM WAV 文件头已用标准读取器核对。
