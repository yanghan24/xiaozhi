## 范围与职责

| 主体 | 职责 | 不承担的职责 |
| --- | --- | --- |
| AI 集市 | 账号认证、用户同意、组织资料、积分、应用业务 Key、资源访问权限和计费 | 音箱硬件身份、设备归属、固件维护 |
| 小智 Java 后台 | 已认证设备的授权事务、客户关联、绑定/退出/解绑、心跳、默认智能体、管理员接口、凭据加密和续期 | 代替集市验证用户密码、在数据库伪造集市授权 |
| 小智 Python 语音 | 验证本台使用权限，按默认角色和归属客户业务 Key 调用模型，完成音频服务 | 自行修改用户归属、固定某个客户的模型 Key、硬编码角色 |
| 音箱固件 | 独立设备认证、显示授权二维码和核对码、上报心跳/固件、录音播放、本台退出/解绑 | 保存集市 Client Secret、模型 Key 或客户刷新令牌 |
| 管理端 | 管理员运营入口；客户和关联设备、硬件及固件运维、默认角色配置 | 普通客户注册或自助创建角色 |

登录由音箱发起。后台调用发现端点中的 device authorization endpoint，保管 device_code；音箱仅收到 verification_uri_complete、user_code、有效期和后台事务 ID。手机直接使用集市页面。后台按 interval 查询并处理 pending、slow_down、拒绝、过期及网络退避；成功结果只能用于发起本次事务的设备。绑定提交前重查设备归属/代际，旧事务不能在解绑后重新绑定。

客户以 issuer + subject 唯一关联；应用凭据同时关联 Client ID。客户可绑定多台设备，设备同时只有一个归属。单台退出保留归属，解绑清除本台归属；两者均不撤销账号在集市的共享应用 Key。断网、重启、关闭手机页不解除绑定。短期令牌到期或续期暂时失败不改写本台退出/管理员停用状态，也不直接判定业务 Key 已失效。

## 数据与配置边界

- `sys_user` 只承担运营账号认证。产品客户单独存储，绝不把集市登录身份提升为管理员。
- 设备 ID/凭据认证沿用已交付的独立硬件身份格式；设备归属、心跳和固件信息以一个设备登记表为准，不建立两个互相同步的设备台账。
- 新的产品客户、应用授权、扫码事务、默认角色和操作记录使用独立表；迁移只增加表/列，不清空历史表或修改历史迁移校验和。
- 集市令牌和业务 Key 由后台使用开发独立密钥加密；不在接口、日志、仓库、二维码或前端状态中暴露。
- 所有端点通过协议发现或环境配置取得；设备应用不使用网站回调、Secret 或集市注销通知。
- 首次必须配置并明确选定可用默认角色才允许语音。当前回答完成后，下一轮采用新默认角色，清空旧会话上下文，保留绑定和已保存历史。
- 角色保存模型引用、提示词和音色，用户 Key 在调用时取得。第二阶段才做模型目录同步及模型配置页重构。

## 管理菜单

用户管理：集市客户列表（绑定数、在线数）、客户详情（资料、组织、余额查询状态及时间、授权状态、关联设备）、绑定/解绑管理。缺失资料标为未提供，余额未知不显示为零。

设备管理：硬件台账（型号、固件、心跳、在线、维护状态）、固件目录和现有 OTA 入口。归属客户只提供关联跳转；不复制一套客户管理。第一阶段不增加批量烧录、OTA 调度、容量扩展或新硬件支持。

智能体管理：管理员创建/编辑角色，选择默认角色；用户暂不能选择角色。

系统设置：原参数字典菜单改名，管理员账号与客户管理明确分开。

2026-11-17 用户补充：新页面沿用当前 UI 风格，优先复用 HeaderBar、CustomTable、CustomButton、CustomPagination、Element UI 表单/弹窗及既有固件组件，不引入新设计系统或前端框架。

## 验收与外部条件

1. 未绑定音箱有集市二维码及核对码；拒绝/过期能主动重发，device_code 不出现在设备响应中。
2. 成功登录取得真实身份与组织资料，客户列表的绑定数/在线数来自实际关系。
3. 已绑定设备不能被另一账号一次登录覆盖；退出/解绑只影响目标设备；旧授权事务和语音会话不能恢复旧归属。
4. 心跳与语音连接分开，未绑定或退出仍可上报；离线由后台超时计算。
5. 默认角色缺失时明确禁止对话；角色切换不改变用户或设备关系。
6. 管理页只允许管理员。用户资料和余额查询失败有可理解的状态，不伪造数据。
7. 模拟通过不作为真实登录、真实模型调用或音箱麦克风/扬声器验收。开发 device Client ID 已由用户提供；真实扫码仍需要用户在手机上确认，不自动代替用户授权。
