| 固件与 OTA | 后台唯一入口为原版 OtaManagement / ai_ota，认证已登记设备按准确板型检查升级；第一批不使用新增固件表、推送桥接、批量/待机任务 |

| 用户及设备页面 | 用户保留资料、组织、积分、绑定数量和认证心跳在线；设备页保留信息/维护记录与原版固件入口，设备在线独立于唤醒对话 |

3. 用户/设备关系、独立心跳、管理员暂停、退出解绑及其他账号重新绑定。
4. 断网/重启恢复、音量/亮度等官方工具、原版 OTA 下载/安装/重启后恢复。
