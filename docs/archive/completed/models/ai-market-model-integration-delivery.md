## 完成内容

- 各类型保留“AI 集市 / 小智系统”两组。集市每用途一个稳定适配配置，从远端目录动态筛选后由管理员选择，不批量导入每个远端模型。
- 网站后端的 client_credentials / models:read 与设备用户授权、资源 Key 独立；目录和个人 Key 均不交给浏览器。
- 兼容条件在列选项、保存和生成运行配置时执行。VLLM 限已验证图片输入；独立 Intent 限 JSON Object 能力；普通摘要 Memory/SLM 使用聊天能力。function_call 模式还校验工具能力。
- ASR 仅 spark_zh_iat_new / xfyun_asr_v2。沿用原版 ASRProviderBase，覆盖 PCM、VAD/手动结束、动态修正、单轮 60 秒限制、取消及最终交接。
- 用户授权增加 credentials:manage，按需领取并加密保存应用专用 Key。登录、绑定不等待资源 Key 领取；未使用集市模型时不要求资源 Key。
- 配置请求携带已经验证的语音会话，领取前后复核设备归属；生成独立配置，避免修改共享缓存。视觉入口同样验证设备身份。
- Java 总结和标题携带原会话标识，按归属用户请求模型；请求失败不能作为成功摘要写入记忆。
- 配置更新只通知实际引用该配置的默认智能体，于下一轮重建原版提供者；无关配置不影响现有会话。原角色、音色、工具、历史、OTA、固件保持既有边界。
- 模型页面按用户反馈调整了布局：来源切换、配置标题、模型选择与能力标签、启用状态、保存操作分区，复用现有组件和配色。

## 定向验证

- Java：25 项相关测试通过，覆盖目录令牌与分页、401/403、字段白名单、能力和协议筛选、保存边界、两用户配置隔离、凭据缓存/领取、会话归属、Java HTTP 调用凭据及失败处理、旧接口绕过防护。
- Python：17 项定向测试通过，包含新 ASR、原版对话与身份边界、JSON 参数和视觉身份校验。
- 前端：3 项定向测试通过；生产构建通过，保留原有资源体积和字体预缓存警告。
- 浏览器：真实管理 API 下验证来源分组、目录选项、保存、仅一个 ASR 候选、未接入类型空状态、1024 宽度布局和完整智能体编辑器；无页面运行错误。
- 新 ASR 提供者真实接口验证：固定 2.345 秒录音、75048 字节 PCM 完整交接，最终文字为“请登录控制面板输入。”，停止后 0.525 秒交回最终结果。
- 用户亲自完成真实设备授权。验证了自动领取该用户的应用专用 Key、后台注入、无效语音会话拒绝及独立意图/记忆配置使用相同归属用户。
- 开发语音联调：模拟音箱发送 Opus，经过真实集市 ASR、真实用户应用 Key、原版 LLM，交给原版 TTS 提供者及 Opus 输出；识别文字正确，回答“收到”，收到 5 个音频包，结束收音到输出完成约 2.752 秒。

TTS 在这次联调中使用本地协议替身，未调用真实合成服务；不是音色、拾音、扬声器、真实设备打断或重连验收。
单次延迟不是性能保证。没有遍历整个集市，也没有测试其他 ASR、向量/重排或复杂记忆。

最终服务重载后再次只读核对目录：LLM 24、VLLM 18、ASR 1、独立 Intent 17、普通摘要 Memory 24。Memory 沿用管理 API 的纯文本摘要路径，不强制独立意图使用的 JSON 输出条件；原 JSON 模式的限制按实际调用路径保留。

## 数据和环境

- 工具、构建与服务重载均在既有 xiaozhi-dev 内。仅使用 104 的小智独立开发数据库和 Redis；没有访问 114、修改 AI 集市实现、安装宿主依赖、重建容器或修改固件。
- 模型配置、默认角色在验收后恢复；临时管理员、模拟设备、测试角色/模型和历史已清理。
- 用户真实授权的账号与加密应用凭据保留在开发环境；不撤销共享应用 Key，不影响该账号其他终端。
- 没有自动启用、选择或设定生产用途的模型。管理员在“模型配置 → AI 集市”选择并启用，再到完整智能体配置中选择对应的 AI 集市配置。
- 网站后端凭证仅在 runtime 私有文件，测试 Key 没有固化为产品公共 Key。提交不含秘密。

脱敏运行记录和页面截图保存在 runtime/xiaozhi/reports/；不将原始认证资料、私人录音或运行配置放入仓库。
