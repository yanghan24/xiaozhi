# 管理弹框统一与布局整理

> **归档｜交付或验证记录**。正文对应当时的版本、范围和结果。当前入口见[项目文档](../../../README.md)。

2026-11-17，按用户确认执行。范围仅 MCP 管理、设备管理、用户管理中新增的五处弹框，不扩展到旧页面或其他模块。

1. 复用原有 `CustomDialog`，统一标题、关闭按钮、滚动区域和底部按钮；不修改公共弹框组件，避免影响原页面。
2. MCP 新增/编辑按基本信息、连接配置、认证配置分组，统一标签与输入宽度，凭据保留/替换/清除说明独立展示，保存和取消复用公共底部。
3. 设备详情按设备信息、运行与归属、维护记录分组；登记音箱使用公共底部登记按钮，成功后仍显示一次性凭据，关闭后清理。
4. 用户详情按基本资料、集市关联、同步信息和绑定音箱分组，保留资料刷新、积分、组织、设备状态和解绑入口。
5. 不改变接口、权限、请求数据、绑定/解绑及凭据规则，不修改后端、固件、模型和语音链路，不触碰 114 或 AI 集市。

## 实施与提交

- 先记录方案并本地提交；实现完成后单独提交，最后记录验证结果。
- 仅在现有 `xiaozhi-dev` 容器使用现有工具，不安装依赖或重建服务。
- 构建并在浏览器检查打开/关闭/取消、分组、滚动、字段保留、凭据清理。真实开发数据只读；若需核对提交事件和一次性凭据状态，使用浏览器内拦截的模拟响应，不执行真实保存、登记、解绑、刷新集市资料或外部调用。
- 本任务承接尚未合入主线的 Tab 布局提交，任务分支从最新 `origin/main` 创建后快进承接该分支。

## 实施结果

- 五处弹框已复用 `CustomDialog`；公共组件和原页面弹框未修改。共享样式仅由这三个管理页面导入。
- MCP 表单分组、输入对齐与底部按钮完成，设备和用户详情分组完成；设备登记成功后仍隐藏登记按钮并显示本次凭据，关闭后清空。
- 最终前端构建通过。浏览器模拟接口核对打开/关闭/取消、MCP 凭据保留/替换/清除与原提交字段、错误 JSON、登记提交字段及凭据清理、用户详情字段和操作入口，以及 1440×1050、1024×768 显示和内容滚动，全部通过。模拟提交 4 次，真实业务 API 请求为 0。
