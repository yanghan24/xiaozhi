# 项目文档归档

归档保存当时的设计、实施、验证和上游参考。接手开发、排查当前系统或操作生产时，先读[现行文档索引](../README.md)。

| 类别 | 归档内容 |
| --- | --- |
| [交付与验证](completed/README.md) | 已实施或开展过验证的方案、交付说明与验收报告。实际验证阶段和结果以记录为准。 |
| [旧方案](superseded/README.md) | 已被后续架构、协议和运行方式替代的草案、接口契约与交接。 |
| [上游参考](upstream/README.md) | 上游源码来源、旧教程和通用参考。 |
| [历史证据](../verification/evidence/) | 报告对应的脱敏样本、日志与快照，路径保留以便复核。 |

文档及证据的生产访问资料已在当前工作树脱敏。当事报告记载的部署、产物或原件校验值仍对应记录日期。对仓库内重新生成的脱敏证据包，通过包旁回执区分现有文件和历史原件。
