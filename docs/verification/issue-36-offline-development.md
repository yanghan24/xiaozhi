## 覆盖和审查修复

已有测试覆盖：issuer 隔离、多 flow/多候选、无匹配与重复收据、sid 优先及无 sid 按 sub、秒与毫秒边界、两账号不独立/缺基线、闲置超时但缺浏览器证据、日志缺失/轮转/截断、时区、输入与命令/SQL 注入防护、正常及失败输出脱敏。

整合测试和只读代码审查发现并修复：
1. 数据源调用 MySQL runner 的参数不一致，真实执行本可能报错；新增接口回归测试。
2. 私有基线的状态、布尔值、目标和日志字段缺少严格校验；浏览器活动时间接受浮点数/空值；均改为严格类型及字段约束。
3. 身份 flow 的 issuer 未与环境配置核对；现在数据库内比较，只返回布尔值，不匹配报环境错误。
4. 数据库别名、JDBC 端口及入口目标不唯一的布局未充分拒绝；现在按支持范围检查，不猜目标。
5. 双账号缺少收据增量连续性校验；窗口检查未约束异常时钟；登录缺少身份存在约束；已补判定和回归测试。
6. 原本通过语法正则放行的理由字符串可能携带短标识；现改为固定公开理由及检查标识白名单，不回显未知字符串。
7. A 的授权若已变化，不能无条件判双账号隔离通过；现保守判证据不足，分别报告状态，不直接归因于 B 退出。

离线测试可以验证生成的 SQL 结构及对应判定模型，但不能证明真实 MySQL 执行语法、索引性能、实际配置或私有格式正确。
