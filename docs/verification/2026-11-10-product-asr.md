# 产品异步 ASR 与真实音频闭环

2026-11-10，#13 分支在 36a5c19 基线上增加产品 ASR。Ubuntu jt@192.168.168.114 的 issue13 隔离数据库、Redis、Java harness 和正式 Python WebSocketServer/ConnectionHandler；未合并或部署生产，未使用物理音箱。

## 受控回归

`scripts/check-product-asr.py` 通过真实 HTTP/WebSocket、MySQL/Redis 和许可接口驱动产品代码，仅替换集市 HTTP 与 Edge 外部传输。验证：

- 20 个连续 Opus 包后立即 stop，临时 WAV 恰好含 19,200 个 16 kHz 单声道采样；识别文字进入模型并产生可播放编码帧。
- 主任务成功但子任务失败、空结果、重定向、慢速持续响应、整体任务超时均失败关闭，不重试提交、不继续模型；结果下载不携带 Key。
- 超长发布被拒，TTL 到期、完成、退出、打断和普通断线后 URL 返回 404。
- 等待识别时继续发送超过 100 帧音频仍保持连接；abort 能及时取消旧识别。退出后未完成识别不能产生模型/TTS。自动模式在已有 TTS 播放时送入新的录音并 stop，内部打断旧播放后仍能把新识别文字交给模型。

最初回归失败暴露重复 Content-Type/Content-Length；修复为替换默认头。公网预检另暴露 Nginx 默认 HTTP/1.0 与 websockets 不兼容，添加 proxy_http_version 1.1 后，从 Windows 经真实 TLS 入口下载 WAV 得到 HTTP 200、audio/wav、38,444 字节。

原有 `scripts/check-product-voice.py` 产品文字/模型/输出闸门回归也通过；Java 本轮未变更，沿用此前 317 项完整测试结果。双轴静态审查发现的代理协议、断线取消、慢响应工作线程、连续音频积压和内部打断自取消问题均已修复并回归。

## 真实集市闭环

使用用户已授权的有积分账号，私有凭据中继在外部边界把合成测试 Key 换成当前真实 Key；真实 Key 没有写入合成设备库、源码或日志。输入为前一轮 TTS 生成的 3.24 秒 WAV，重采样到 16 kHz 后编码 Opus，经正式设备协议输入；不是 listen.detect 文字替代。

成功一轮：

| 检查 | 结果 |
| --- | --- |
| qwen-audio-3.0-asr-flash-filetrans | 提交一次，任务成功 |
| 真实识别文字 | 你好，语音测试成功。 |
| qwen3.8-flash | 请求一次，HTTP 200，SSE DONE |
| 真实模型回答 | 你好，语音测试成功。 |
| Edge TTS / WebSocket | 54 Opus 帧，解码 WAV 3.24 秒，24 kHz 单声道 16 bit |
| 单台退出 | 连接关闭，后续模型调用拒绝，旧语音令牌拒绝 |

测试中继限制模型 max_tokens=128、enable_thinking=false；这不是产品默认参数。此前两次提交返回 FILE_DOWNLOAD_FAILED，未进入模型或 TTS；原因是测试代理未显式启用 HTTP/1.1。修复并完成无付费公网预检后成功，未对失败任务自动重放。总计三次实际 ASR 提交、一次实际模型调用。

成功记录在增加非阻塞连续收音/abort 处理前完成；随后该调度增强由上述受控回归覆盖，未重复付费调用。私有结果与可播放音频保存在隔离运行目录，能力 URL、任务标识与账号凭据不入库。测试临时公网路由与网络连接已移除，明文临时 Key 已清理；原身份服务保持运行。

## 尚未验收

合成产品设备许可 + 真实外部 Key 中继不等于真实账号与该设备完整绑定。物理麦克风、扬声器、固件动态二维码、独立设备凭据交付、停播 ACK 和最终手机/真机闭环仍待验收，#11/#13 保持开放。临时 URL 是短期能力凭据，不是集市身份认证；集市已下载的数据及已受理任务的保留/计费由集市决定。
