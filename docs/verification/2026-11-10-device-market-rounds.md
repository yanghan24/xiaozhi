新增结构化 `market_request` JSON 日志已部署。每条 ASR/LLM 请求保存独立随机 request ID、操作类型、UTC 起止时间、最后阶段、各阶段起始偏移、总耗时、适配 HTTP 状态、最近上游 HTTP 状态、上游结构化错误码（存在时）及异常类型；ASR 上传文件名符合已有格式时提取 session UUID，不保存完整文件名。LLM 记录首次收到流式字节时间，这不是首个有效回答字符、TTS 首音或实际播放时间。

日志不输出录音、识别文字、问题、回答、完整错误 body/message、Key、Authorization、下载 URL 或 task ID。没有上游 HTTP 响应、结构化 code 不存在时对应字段为 `null`，不编造错误码。ASR 提交、轮询、结果下载分开记录，HTTP 200 但任务/子任务失败仍作为失败输出。阶段时间是该阶段第一次进入时的偏移，轮询总时间可用相邻阶段偏移计算。
