复制本模板为带日期的记录再填写。`待测` 不能改写为通过；附上本轮生成的脱敏证据路径，不沿用旧报告。硬件已确认可修改 OTA 地址，固件仍在修改，使用本轮可运行的测试版本即可，无需等待最终版。

## 逐项结果

| 检查 | 状态（通过/失败/待测/不适用） | 本轮证据与观察 |
| --- | --- | --- |
| 从设备网络实际 POST OTA URL，取得预期激活响应 | 待测 | 记录来源网络、HTTP 状态和脱敏响应；不要仅记录服务器本机 curl |
| OTA 下发的 WebSocket 地址可由设备到达 | 待测 | 记录 TCP/握手/协议响应，不仅是 DNS 解析 |
| API 容器与协议客户端可到达同一 WebSocket URL | 待测 | 记录真实协议检查结果 |
| 管理页和管理 API 未经设备入口公开 | 待测 | `/`、`/xiaozhi/user/pub-config`、`/xiaozhi/admin/params` 返回 404 |
| 未绑定设备激活、绑定、设备回读 | 待测 | 记录本轮测试账号及设备关联，脱敏激活码 |
| 设备认证，错误令牌被拒绝 | 待测 | 不保存实际 token |
| hello 与对应会话 ready | 待测 | ready 属于本轮会话；HTTP ready 走同一设备入口 |
| 麦克风采集与远程 ASR 识别 | 待测 | 测试语句、识别文字、时延及失败原因 |
| 真实 LLM 生成 | 待测 | 预期/实际文字；不是占位凭据初始化 |
| TTS 经设备协议下发并由设备播放 | 待测 | 现场确认语音内容、完整性与音质 |
| 打断、连续对话、连接保持 | 待测 | 场景、时长、重试行为 |
| 断网再连、设备重启 | 待测 | 绑定保留、地址保留、重新认证及对话恢复 |
| 小智服务重启及同设备持久化 | 待测 | 只操作小智项目；保留相同测试设备、账号与智能体，比较重启前后绑定/配置并再次对话 |
| 本轮测试数据和临时模型清理 | 待测 | 保留应保留的真实设备/账号，不清空共享数据库 |

协议模拟器的 `scope: device_protocol` 及会话 ready 不能代替麦克风、模型实际调用和设备播放验证。单独的 Edge TTS 文件生成也不表示设备音频链路已通过。

`check-voice.py` 每轮生成新身份并清理测试设备；重启前后各跑一轮不能证明同设备持久化。#5 另用一份保留到复验结束的专属测试设备/智能体与账号，记录重启前后的脱敏设备 ID、归属、智能体/模型配置及 URL。真实样机也应保持相同设备身份。复验结束后再清理明确属于本轮的测试对象。
