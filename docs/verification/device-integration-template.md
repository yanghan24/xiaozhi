# 单设备联调记录模板

复制为带日期的验证记录后填写。按照[协作规则](../../CONTRIBUTING.md#生产环境与实机验收)区分开发验证、生产发布核验和真机验收。生产及真机操作先确认授权、设备和范围。

## 版本、设备和范围

| 字段 | 实际值 |
| --- | --- |
| 日期、时区、执行人 | 待填写 |
| 验证类型、环境标识和范围 | 开发检查／生产发布核验／真机验收 |
| 音箱硬件和上报板型 | 待填写 |
| 固件版本、源码提交与构建变体 | 待填写 |
| 应用镜像 SHA-256 | 涉及构建或刷写时填写 |
| 服务源码与运行镜像 | 待填写 |
| 设备标识 | 使用脱敏标识 |
| 设备可达的小智 HTTPS 与 WSS 业务入口 | 记录业务路径和证书校验结果 |
| 默认智能体、ASR、LLM、TTS | 记录非秘密的配置标识 |

## 检查结果

| 检查项 | 结果 | 证据及备注 |
| --- | --- | --- |
| 首次联网、设备登记、认证心跳 | 待测 | 记录是否取得设备状态、认证失败时的结果 |
| 扫码授权、绑定、本机解绑 | 待测 | 记录脱敏设备状态和归属变化 |
| WSS、唤醒、收音及识别 | 待测 | 记录协议或真机范围及转写结果 |
| 智能体、模型、工具与播报 | 待测 | 记录实际调用、工具结果、播放及打断 |
| 断网再连、设备重启和身份保留 | 待测 | 使用同一设备检查前后状态 |
| 按板型 OTA 检查、下载与安装 | 待测 | 分别记录目录版本、下载校验、启动版本与实际心跳 |
| 本轮其他功能 | 待测 | 填写具体触屏、诊断或本地应用检查 |

结果填写通过、失败、待测、受阻或不适用。协议模拟只证明模拟覆盖的行为。真实业务凭据、生产访问资料、客户录音和私有日志保存在仓库之外。证据只提交脱敏版本。
