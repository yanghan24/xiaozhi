## 行为与证据

原本 `sign-out` 只停用并保留账号归属，新固件改用专用 `POST unbind`，按钮及确认提示明确说明会解除绑定。后台在同一事务停用本台、清除归属、递增许可及归属代际、替换旧请求；同版本失败保持本机停播，明确提示重试，不把旧停用状态当成解绑完成。旧手机/旧固件的停用接口保留原语义。

## 尚待部署与实物验收

配套 API 和公网 `unbind` 精确路由尚未部署，新固件尚未烧录。本轮不把可控集市 HTTP 测试或旧版双机恢复报告当作真实跨账号验收。先部署配套服务并执行更新后的只读公网预检，再安装新固件，使用另一真实账号确认绑定、语音、停播 ACK、旧页面失效及第二台仍可回答。此前单次唤醒重启根因仍未定位。

已经完成的解绑属于持久业务状态，回退代码不会恢复旧归属，也不能用旧备份覆盖新账号。
