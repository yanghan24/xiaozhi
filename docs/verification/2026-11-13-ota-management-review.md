## Standards

## Spec

首次独立审查发现一项 P2：逐台两分钟预览期限可能在批次预检或确认后的排队中耗尽，导致本可升级的设备未发送。`5d5a992` 在全部预检完成后发布统一确认窗口；已确认批次的目标保留该授权，同时按管理员、固定清单与状态验证资格，发送前仍检查实际会话、权限及兼容性。单台独立确认仍执行过期保护。

新的独立审查未发现剩余需求问题；两条 HTTP 回归分别覆盖预检超过原期限，以及四个工作器中第五个目标排队超过原期限，后者还核对重复确认不重发。持久预留和启动时中断分类保持。

## 证据边界

两轮审查为只读静态审查，不另行声称运行测试。执行结果见 #96/#97/#98 及修复验收文档。#99 的物理安装仍等待不同的已核验固件；旧 UART 与协议模拟不能替代本轮新安装证据。服务候选与配置准备也不等于已经上线。

结论：首次 Standards 2 项判断性建议、Spec 1 项 P2；修复复审两个方向均为 0 项剩余发现。
