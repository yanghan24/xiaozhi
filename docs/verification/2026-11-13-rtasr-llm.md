## 验证结果

- 10 项 HTTP／WebSocket 转写接口测试通过：原生结果与字符串 data、临时消息序号、最终标点、取消后下一段、无效音频、超时、普通错误不撤销、401 阻断另一连接、沉默期间权限失效，以及带 40 ms 权威接口延迟的发送节奏。
- 正式设备 WebSocket／ConnectionHandler + 真实 Java 权威服务 + 独立测试数据库通过：Opus → rtasr-llm 协议 → 对话模型 → TTS 音频、手动 stop 排空队列、播放打断、新会话、取消／断线清理和退出后禁止后续模型／TTS。集市与 Edge 传输在该套件受控替代，未操作真实设备。
- 真实 Java 的模型／ASR 握手 401 跨连接撤销通过。持久上报 503 故障恢复套件通过，包括进程重启、其他账号隔离、旧许可隔离、明确恢复及容量故障。此次未重跑 timeout／lost_ack 两种上报故障模式。
- 最终候选镜像使用当前获准设备账号的业务 Key 调用真实集市，3.408 秒合成语音识别为“你好，小智。请问今天的天气怎么样？”。这不是客户录音，也不是物理设备验收。临时明文 Key 文件已删除。
- Standards、Spec 两项独立审查均发现原发送节奏叠加权限检查耗时的问题。先补失败回归，再改为权限检查与单调时钟节奏并行等待；复审均无剩余可操作问题。真实集市发现的临时消息序号差异也已回归覆盖。
