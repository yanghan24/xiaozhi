# P4 音箱设置

待机页「音乐」右侧的「设置」沿用原面板、字体和按钮。语音连接、聆听和回答界面右上角也保留设置入口，播放时可直接打开。登录后的用户名和积分在打开面板时读取，也可以点「刷新」。只在需要补授权时使用「扫码授权」。点「退出登录」并确认后，音箱立即停播，等待后台确认；恢复时使用原归属账号扫码。

「Wi-Fi」显示当前网络。点「断开 Wi-Fi」仅断开这台设备，保留已保存网络；点「连接 Wi-Fi」按原有配网顺序连接。需要新网络时点「更换网络」，使用原配网热点。离线提示及扫码屏右上角保留设置入口。

## 安装和验收

- 先由 Ubuntu 执行者验证并部署支持 `GET account` 和 `POST sign-out` 的设备控制 API。未升级 API 时，旧语音仍可用；设置会提示账号信息或本机退出暂不可用。
- 样机已经完成在线交付。后续升级使用 USB 应用槽维护流程：先核对本机硬件标识、当前启动槽和现有 16 MB 分区表，备份当前应用，再只写实际启动槽对应的产品应用镜像并读回核对。保留 bootloader、NVS、otadata 和 assets。回退使用同一槽位的已验收应用备份。当前公网 OTA 只做设备控制地址发现，不分发固件；在线交付的 `replace-product` 也只适用于尚未完成交付的设备。
- 打开设置核对真实账号和积分；播放时在音箱确认退出，检查停播、后台 ACK 和扫码恢复；验证第二台仍可语音。保持本台通电，断开 Wi-Fi 并等到原租约期限之后，确认设置仍可访问；重新连接后验证语音恢复且绑定没有改变。
