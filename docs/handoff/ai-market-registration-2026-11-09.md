# 发给集市开发者：小智 web 应用登记与联调信息

更新日期：2026-11-09，Asia/Hong_Kong。可将本文提供给集市开发者和超级管理员，依据《元筑AI集市应用接入接口文档(1)》第 1 节在“系统管理 → 应用接入”核对、登记。本文是登记信息表，不是注册 API 请求。

## 本次对接说明

小智智能音箱采用“手机扫描设备二维码 → 小智绑定网页 → 集市 OIDC → 小智服务端回调 → 手机确认”的方式。客户端类型采用 **web**；令牌兑换、刷新及调用 Key 保管均在小智服务端完成。请先核对并复用已有同用途 web 客户端和测试账号；如尚未登记，再按下表创建。不要因终端是音箱而登记为 device 类型。

公网入口已验证 HTTPS/WSS，设备 OTA 和语音地址已发布。下表的登录回调、注销通知地址依据已确定的设备绑定 v1 契约组成，**目前尚未部署，实测均返回 404，仅供预登记和双方确认，不能立即开展登录或通知验收**。小智侧负责实现及放行这两个路径，完成后再通知集市联调。

## 请集市侧反馈

1. 已有应用是否可复用；返回实际 Client ID、客户端类型、获准 scope、刷新授权设置及精确回调/通知登记值。Secret 走私密渠道，若已交付请核对交付位置；文档列出的能力不代表本客户端已经获准。
2. 确认接收含非默认端口 `:18443` 的 web HTTPS 回调与后通道通知地址。待小智实现后，由手机浏览器访问回调、集市服务器投递通知分别验收。
3. 复用已有独立测试账号，确认规范通权限及测试额度；双账号隔离验收时核对第二个独立账号，以及无应用权限、授权失效等测试状态的准备方式，不重复索取密码。
4. 核对集市网站、OIDC、微信/集团等外部退出分别会产生哪些通知，通知按 `sid/sub` 关联的范围、投递失败限制及会话自然到期约定。小智单台退出不触发共享授权撤销，也不承诺同步退出集市网站。
5. 协助定位上述服务器出站 443/4090 无回应；网络及小智回调实现齐备后，安排首次 consent、真实刷新轮换及应用授权撤销联调。授权撤销使用专属测试授权，避免影响其他终端。

## 业务与退出边界

设备档案、绑定、解绑、转交和单台调用许可由小智维护；集市负责身份、应用权限及额度计费。首次绑定只需手机明确确认，不要求音箱端再次点击。一个集市账号可绑定多台音箱，每台同时只有一个归属账号。

小智页面的“退出登录”仅持久停用当前设备并停播，保留归属；不调用 OIDC 全局退出、`DELETE /api/oidc/authorization` 或共享 Key 撤销接口，不删除共享 Refresh Token。恢复需原账号对本次目标设备重新确认，其他已退出设备保持停用。真实上游撤销、账号停用和权限失效仍按其实际影响范围处理。

规范通原生会话 API 的 `app_id` 为 `e7446555-5f01-4aab-b749-7b2683b7e4e9`；控制台/MCP 标识为 `156fd2a5-ade8-4800-b206-21a024d23760`，两者不能互换。请核对用户权限与对应资源，计费按实际调用 Key 所属账号执行。正式 TTS 契约尚待开放，当前 Edge TTS 测试不表示集市合成已经接通。
