# 首版改为 MCP 知识库问答（2026-11-10）

用户明确将本期“接入智能体”需求改为接入今天验证的 AI 集市 MCP 知识库；后续确有智能体接入需求时再补充规格和任务。总规格及任务以 GitHub #10、#12、#14、#19 的最新正文为准。

## 本期范围

- 小智语音服务使用当前模型 `qwen3.8-flash` 调用 MCP 知识库工具 `ask_knowledge`，依据结果生成回答，再由默认 Edge TTS 合成并返回音箱播放。
- 接入目标为 `service-669a396c73`，SSE 地址为 `https://aimarket.hncig.cn:4191/mcp/service-669a396c73/sse`。这是知识库工具服务，不是此前规范通智能体的 Streamable HTTP 接口；不能沿用其 app_id、conversation_id 或事件协议。
- 智能体选型、规范通恢复、其他智能体调用及集市 TTS 均不作为本期前置条件。未来智能体需求另行补充，不预建第二套接入路径。
- OIDC 身份、设备归属、本地调用许可、单台退出及恢复、上下文隔离、记录保留和运营权限规则继续适用；新模型调用、知识库工具调用和 TTS 输入均受设备许可约束。

## 已有证据及边界

依据同日聊天“Check MCP knowledge-base access”的后端测试记录，`qwen3.8-flash → ask_knowledge → 回答` 已成功回答“怎么申请成立社会团体”和“境外非政府组织的登记和备案”，来源为《社会组织工作资料汇编（2026年）》。这是已有测试记录的归纳，本次需求修改未重新运行测试。

测试曾出现 `status=incomplete`、`generated=false` 且返回原文摘录，随后重测出现 `status=ok`、`generated=true`。成功样例不能证明偶发不完整结果已根治；有检索片段也不能当作完整归纳成功。设备日常对话、实际扬声器播放、多客户授权和容量尚未由这些样例验收。

## 实施与验收分工

- **#12：知识库契约。** 固化 SSE 初始化、工具定义、必填参数、结果/来源/错误、超时与取消语义；区分 MCP 工具传输成功和业务回答完成。确认 MCP Bearer 凭据的归属、授权范围、续期/撤销、计费与集市登录账号的关系，不能从单个测试凭据推定所有客户均获授权，也不能将 OIDC Token、模型 Key 和 MCP 凭据混用。凭据仅保存在受控后端。
- **#14：真实设备闭环。** 将模型与知识库工具接入真实设备日常对话；按账号、设备和本次连续对话隔离上下文，保留来源用于核对，播报略过网址和引用编号。不完整、无命中、拒绝、超时及工具失败不得伪装成知识库完整回答。验证打断、退出后无新调用、迟到结果丢弃、重登恢复及重启。
- **#19：容量与最终验收。** 按 2026-11-10 用户确认的[容量验收目标](product-rules-2026-11-09.md#50-路容量验收)，采用 10/25/50 路阶梯，50 路至少 30 分钟、每路至少 10 轮、完成率至少 99% 及零账号串用/退出后调用/串音。完整链路改为接入、ASR、模型与真实 MCP 知识库调用、Edge TTS 和完整音频返回；测试问题集须实际触发知识库工具，不能仅测模型直接回答或缓存成功样例。不完整结果计入失败，不用重试覆盖首次失败。

## 与既有决定的关系

本次调整替换 ADR-0001、ADR-0005 中“本期调用集市应用”的接入对象，不改变集市负责账号和实际资源权限、小智负责设备管理的职责。未来资源权限和计费以实际契约确认；不推定知识库凭据与原应用 Key 具有相同生命周期。旧规范通资料与历史测试保留为参考，不构成本期实施要求。
