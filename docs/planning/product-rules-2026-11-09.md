# 首版产品规则收口（2026-11-09）

用户通过本轮 grill-with-docs 逐项确认 Q1–Q7。本文记录已确认的行为与验收口径，供总规格 #10 和任务 #11/#13/#15/#16/#17/#19 使用；不代表实现或真实验收完成。接口事实仍以集市正式契约为准。

## 客户网页与音箱授权

- 客户设备页面闲置满 30 分钟后，操作前须重新确认身份。自动轮询和后台刷新不能冒充客户操作延长闲置时间；由服务端判定过期。
- 网页关闭或自然到期只影响网页操作，不停用已获准且集市授权有效的音箱。设备绑定请求 600 秒、OIDC 技术事务最多 300 秒、授权码 60 秒、访问令牌 5 分钟各自独立，不替代客户会话期限。
- 小智页面主动退出仅停用目标音箱，保留归属和设备接入凭据，不撤销共享 Key、Refresh Token 或应用授权。原账号重新确认并取得有效授权后，仅恢复本次目标设备。
- 确认当前授权无法续期恢复时（包括刷新令牌闲置失效），停用依赖该授权的音箱本地调用许可，保留归属，提示原账号扫码重新授权。Key 可能仍可用，但不能据此继续调用；本地停用不宣称集市已经撤销 Key。
- 普通网络超时、5xx 和未知执行结果不能直接判为授权失效，也不能盲目重放旧刷新令牌。旧授权的迟到失败不能误伤新授权；一次重新授权不自动恢复其他停用设备。
- 后续确认：当刷新结果未知且旧刷新令牌不能安全重试时，状态为“授权待确认”，暂停依赖该授权的新模型/知识库/TTS 调用，保留归属与共享凭据，提示原账号重新授权；不声称集市已撤销授权。具体状态、在途输出和恢复约定见[身份模块接入约定](../contracts/customer-identity-integration.md)。
- 验收分别覆盖网页过期但音箱可用、过期网页变更被拒、临时网络错误、当前刷新链不可恢复、多设备停用及仅恢复目标设备。

## 50 路容量验收

2026-11-10 用户确认将完整语音容量验收目标由 100 路调整为 **50 路**，压测阶梯为 **10/25/50 路**。本次调整的是验收目标，不新增运行时并发准入上限；容量仍待实际验收。

2026-11-10 提供者范围更新：本期接入 MCP 知识库，智能体需求留待后续；默认 Edge TTS。详见[范围与证据](mcp-knowledge-scope-2026-11-10.md)。以下质量门槛保持。

- 保持 50 路在线，持续运行完整语音负载至少 30 分钟，每路至少完成 10 轮问答，并安排 50 路同步发起的轮次；不得以空闲连接或一次集中请求代替持续测试。
- 当前模型与 MCP 知识库的真实调用和默认 Edge TTS 必须参与，链路包括接入、ASR、模型及知识库工具、合成和音频返回。测试问题须实际触发知识库，不完整结果计入失败；依赖未就绪则保留待验收，不用 mock 代替。协议模拟客户端须先经真机校准，报告区分模拟音频接收与真实扬声器播放。
- 端到端完成率至少 99%。统计分母为该负载窗口发起的全部正常问答尝试；分子为同一尝试完成整条链路并收到完整音频的轮次。失败、超时、断线、限流不能剔除，也不能用成功重试覆盖首次失败。测试前固定问题集、发起计划和测试超时，报告给出原始计数及每路完成数；测试超时不是新增产品延迟 SLA。
- 账号串用、退出后继续调用、设备间串音必须为零；专项退出场景与正常问答完成率分别报告，不能用总体成功率掩盖权限错误。已被集市受理的在途请求继续执行不等于退出后发起新调用，本地仍须停播和丢弃旧结果。
- 记录首段音频/完整响应耗时、错误、断线、资源和配额；不设置本轮未约定的延迟门槛。10/25/50 路阶梯继续保留；正式依赖未就绪则保留待验收。

## 文字记录、运营权限与备份

- 每条文字记录按其产生时间满 30×24 小时到期；问句和回答分别保留产生时间，不因后续会话、转交或恢复而延长期限。
- 到期立即不可查询，正常情况下到期后 24 小时内物理清理。清理任务中断不能使过期内容重新可查；故障恢复后补清，超出清理时限应如实记录。
- 首版所有运营角色（包括超级管理员）都不开放完整对话查看、导出或通过其他管理 API 读取正文；客户自助历史门户继续不在范围内。排障使用脱敏错误与请求标识，不把正文搬进日志绕过限制。今后若开放正文访问，需另行确定授权与审计流程。
- 首版不备份对话正文，只备份设备归属、配置等必要业务数据。不允许完整数据库、数据卷或日志快照间接包含正文；备份设计及恢复演练必须验证排除结果。原始录音仍默认不持久化。
- 用户接受故障时尚未满 30 天的文字记录也可能无法恢复。恢复业务前检查过期内容不可查询、正文未从备份重新出现，必要时先补清。已退出设备不得因恢复旧状态重新获得许可。
- 上述保留与备份规则适用于小智侧；集市侧的保留和清理能力另行核实，不将本地删除称为远端删除。

## 账号找回

原账号无法登录时走集市账号找回渠道，小智运营协助定位问题；找回后由原账号重新认证并解绑。首版不提供人工强制换绑，也不因补发设备凭据改变归属。集市实际支持入口仍需核实，这不阻塞“不强制换绑”的明确行为。
