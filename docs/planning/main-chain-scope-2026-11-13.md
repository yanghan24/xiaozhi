# 单台主链范围收缩

2026-11-13，用户要求先确保“登录 → 语音回答 → 语音回答自动调用 MCP 知识库 → OTA 更新”能够快速测试，其余工作放进 backlog。本次调整交付范围、验收出口及任务依赖。当前执行规格为 [#10](https://github.com/yanghan24/xiaozhi/issues/10)，延期入口为 [#88](https://github.com/yanghan24/xiaozhi/issues/88)。

## 执行基线

使用一台现有已登记 P4、一个获准测试账号和现有 Ubuntu 测试服务，复用正常联网、OIDC、设备准入、ASR、模型、Edge TTS 与单台 OTA。客户自然提问即可触发知识库；验收包含真实工具调用、模型依据检索结果续答和音箱实际播放。OTA 后在同一设备复测普通问答及知识库问答。

本轮只修复阻断该路径的问题。操作步骤及通过条件集中在 [#19](https://github.com/yanghan24/xiaozhi/issues/19)，具体实现入口为 #12、#13、#14、#18。此次范围调整没有执行新的设备测试，也不证明这些功能已全部可用。

- 主线 `6bf7620` 的产品模型工具入口明确拒绝调用，产品连接使用 nointent。配置 MCP 地址仍不足以形成产品问答；#14 负责接入已有工具能力。

- 已有 PR 保持原状态；主线版本与实际部署版本分别核对。运行服务或实机测试前读[当前部署入口](../deployment/current.md)与最新证据，遵守 [CONTRIBUTING](../../CONTRIBUTING.md#测试环境)。
