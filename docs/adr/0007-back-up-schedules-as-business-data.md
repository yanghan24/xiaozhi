# 日程作为独立业务数据保存并备份

用户于 2026-11-10 确认日程按归属账号与创建设备隔离，未结束的日程持续保存，完成、取消或最终错过后再保留 30 天，并作为独立业务数据备份以支持故障恢复。相较于沿用对话正文不备份的规则，这一选择增加了日程内容副本的保留与恢复管理，但避免把长期重复日程当作短期对话记录丢弃；运营人员只能查看状态，不能读取日程正文。备份与恢复必须落实同一到期及访问边界，恢复不能使已结束、已退出或已转交设备的旧提醒重新生效；[ADR-0006](0006-exclude-conversation-content-from-backups.md) 对对话正文的排除继续适用。
