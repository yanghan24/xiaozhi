# 设备管理及绑定归属由小智管理后台维护

用户在 PR 审核中明确设备管理属于小智管理后台，纠正此前将“设备关联集市账号”理解为“设备由集市管理”的记录，本决定替代 [ADR-0002](0002-market-owns-device-bindings.md)。小智管理后台维护设备档案、设备与集市账号的绑定关系、设备运行状态及 OTA 发布；AI 集市负责账号与微信身份关联、OIDC 身份认证、应用权限和额度计费，使设备管理与现有小智服务端能力保持一致。

## 对接影响

客户扫描设备二维码进入小智侧绑定页，通过集市 OIDC 确认身份后，由小智管理后台校验绑定请求、记录该设备与集市账号的关联，并向设备提供生效状态。绑定、解绑、归属查询及转交由小智侧设计和实现；集市提供身份、应用权限、应用调用及计量结算接口，不承担设备管理。

一个集市账号可以绑定多台设备，每台设备同一时间只有一个归属账号，转交前须原账号授权解绑。小智语音服务依据小智管理后台的设备归属记录，按集市正式授权契约检查归属账号的应用权限并处理计费；客户绑定入口与运营管理权限分离，首版客户无需登录小智管理后台。
