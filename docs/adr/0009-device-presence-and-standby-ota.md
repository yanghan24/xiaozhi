# 设备在线与固件维护独立于语音会话

用户要求开机联网即可在后台显示在线并安排 OTA。复用本台独立接入凭据保护的管理连接记录设备在线，并为配套固件增加空闲领取和确认升级的协议；客户语音许可继续只决定客户资源调用。这样已退出、未绑定的设备仍能接受管理员维护，而不会恢复语音权限或改变归属。

语音连接按需建立，不能作为设备在线的唯一依据。旧固件保留现有语音 OTA 路径用于首次安装配套固件；后台分别显示设备联网、升级通道与首次升级条件。此次仅支持发布时在线且兼容的固定目标，离线任务排队继续留在 backlog。

升级命令与接收确认持久绑定设备凭据、启动标识、原运行产物和固定目标。服务器记录命令是否已提供给设备，固件先保存操作再确认并执行一次；重启后核对目标运行产物和有效启动状态。未知结果不能通过服务重启、请求重试或设备重启变成新的写入。
