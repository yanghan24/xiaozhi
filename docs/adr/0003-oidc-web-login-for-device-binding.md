# 通过集市 OIDC 完成设备扫码网页登录

集市提供 OIDC 登录能力，已选音箱具有屏幕，用户据此决定首版采用设备屏幕显示二维码的网页登录和绑定流程，不开发微信小程序。集市处理微信身份关联与设备归属，小智保留管理后台和语音服务；这一选择复用已有集市身份能力，并将首版客户入口集中到网页。具体授权回调、设备绑定会话以及固件显示二维码的契约需与集市和真机联调确认。

## 首版访问范围

用户进一步明确首版客户不登录小智管理后台。客户网页入口用于集市身份确认和设备绑定，小智管理后台供运营管理员使用；完成客户 OIDC 登录不代表获得管理后台权限。此前客户在小智后台查看或删除记录、查询 OTA 结果的界面从首版范围移出，文字记录的 30 天保留与到期清理规则继续适用。
