# 本机确认退出时允许解除设备绑定

用户在 2026-11-11 确认，音箱设置中的「退出登录」改为「退出并解除绑定」：能操作本台音箱的人，经明确确认即可停播并释放本台归属，不再要求原账号到手机授权解绑，随后任何集市账号都能扫码接手。这修订 [ADR-0005](0005-backend-owns-device-management.md) 中转交一律须原账号授权解绑的要求，为设备本机确认增加明确例外，以满足手机首次扫码后无需继续管理音箱的使用方式。

后台仍负责维护唯一归属；设备凭据证明准入身份，不变成集市凭据。解绑须同时停用本台许可、递增归属代际、作废旧请求，使原账号的旧页面、二维码和在途操作不能影响重新绑定后的设备。原账号其他音箱、共享集市授权和已有对话记录不随本次操作改变。手机页面及旧固件的单台停用接口继续保留原语义；运营强制换绑不在本次范围。
