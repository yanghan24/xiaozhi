# 设备绑定由 AI 集市管理（已废止）

早期文档将“设备关联集市账号”误记为“设备由集市管理”。用户在 PR 审核中明确设备管理属于小智管理后台，本记录由 [ADR-0005](0005-backend-owns-device-management.md) 替代，不再作为实现依据。

## 继续适用的使用规则

一个账号可绑定多台设备，每台设备同一时间只归属一个账号，原账号解绑后才能转交。任何人使用这台音箱时，均以归属账号的权限调用规范通。

2026-11-10 补注：上述账号与设备归属规则继续适用；其中规范通接入对象已由 [MCP 知识库问答](../planning/mcp-knowledge-scope-2026-11-10.md)替代，智能体接入留待后续。本文已废止的设备管理职责不恢复生效。
