# 恢复上游运行链路，身份接入与集市模型接入分阶段

**现行范围**。稳定基线采用上游语音与智能体运行链路。集市身份、模型接入和设备管理沿用各自模块，OTA 使用原版固件目录按板型检查。现行模型、MCP 和本地应用范围见[项目 README](../../README.md)。下文的第一阶段和后续阶段是实施顺序记录。

## 决策与历史实施顺序

2026-11-17 用户确认：采用固定官方基线恢复完整服务端和固件运行能力。114 只提供待筛选的角色提示词和 MCP 配置资产，其设计和实现不作为复用依据。现有功能按清单重新迁移，不因已实现或已合并而默认保留。

本决定细化 ADR-0004，并修订 ADR-0010 所对应实施中将用户绑定、语音使用资格与集市模型 Key 绑定的做法。第一阶段集市只负责扫码身份、用户资料与用户设备关系，语音使用原版提供者和管理员配置；集市模型目录、协议、用户模型 Key 与计费属于下一阶段。后台仍只供管理员，角色完整配置和全局默认规则保持。

语音回归原版配置加载、ASR/LLM/TTS 提供者、对话/记忆/意图/工具、音频收发与打断机制，不另设产品专用处理器；身份校验放在连接和必要业务边界，解绑停用终止相关会话，不逐帧/逐 token 同步远程查库。

设备档案和认证心跳独立于语音。第一批固件采用原版设备工具与 OTA 检查、下载、安装、重启流程，适配新身份。ADR-0009 的设备在线需求保持，旧待机维护协议实现不自动迁入。本轮不使用新增 ProductOtaCatalog/ProductOtaPush 链路。额外展示与本地功能等待第一批真机验收后另行实施。

方案与证据见[实施方案](../archive/completed/voice/upstream-restoration-phase1-plan-2026-11-17.md)及[实施记录](../archive/completed/voice/upstream-restoration-progress.md)。
